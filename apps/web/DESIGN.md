# Clause 디자인 원칙

## 확정 기준

- 화면이 있는 웹 제품, 콘텐츠 중심의 문서·계약 B2B SaaS
- 뉴트럴 미니멀 스타일, 문서 뷰어 배치, light/dark 컬러 모드
- 액센트 `#2563eb`와 그 파생 색을 사용한다. 조직·멤버·권한을 화면 구조에 포함한다.

## 원칙

넓은 여백과 큰 제목으로 문서의 우선순위를 드러낸다. 한 화면에는 한 가지 다음 행동만
제안하고, 긴 문서는 읽기 편한 줄 길이(45–75자)와 넉넉한 행간(1.7)을 사용한다.
색·간격·타이포·반경·그림자는 `src/styles/tokens.css`의 토큰만 사용한다. 본문과 배경의
텍스트 대비는 WCAG AA 4.5:1 이상을 목표로 하며, 모든 조작 요소는 키보드 포커스를 보인다.
hover는 표면 대비 변화, focus는 액센트 링, disabled는 낮은 불투명도, error는 위험 색의
테두리와 안내 문장으로 표현한다. 모서리는 부드럽지만 과장하지 않고, 그림자는 얕게 쓴다.

## 실행

루트에서 `pnpm install` 후 `pnpm dev`를 실행한다. 데이터는 `src/lib/mock-data.ts`에서
제공하며 DB, 인증, 외부 API 또는 필수 환경 변수에 의존하지 않는다.
